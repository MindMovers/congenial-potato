# UDHBHAVA — Where Potential Meets Possibility

**UDHBHAVA** is a complete full-stack web application designed for students in Andhra Pradesh and nationwide. It provides end-to-end guidance from Class 10 stream selection, interactive opportunity node graphs, course comparators, AI pass-assurance exam notes, AP/National scholarship matching (JVD/NSP), EMI loan calculators, cross-stream skill-gap analytics, AI resume builders, company-specific mock interviews, and a bilingual AI companion (Telugu & English).

## Tech Stack
- **Frontend**: React 18, TypeScript, Tailwind CSS v4, Lucide React Icons
- **Build Tool**: Vite
- **Deployment**: Vercel SPA Rewrite Configuration (`vercel.json`)

## Getting Started

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```
